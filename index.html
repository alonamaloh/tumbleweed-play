Install on Linux

Make the AppImage executable in your file manager, then open it. Or run:

chmod +x FILENAME.AppImage
./FILENAME.AppImage

Replace FILENAME.AppImage with the downloaded filename. If mounting is unavailable, run it with --appimage-extract, then open squashfs-root/AppRun.

Other distributions and Wayland need tester confirmation. The standard edition is CPU-only; AMD/Intel GPU acceleration is not included.

Install on macOS
  1. Open the DMG and drag TumbStone Alpha to Applications.
  2. Eject the disk image, then open the app from Applications.

This alpha is ad hoc signed and is not notarized. If macOS blocks it, check the download source, attempt opening it, then use System Settings → Privacy & Security → Open Anyway if offered.

Do not disable Gatekeeper globally. The first use of each board size takes longer while Core ML compiles its model.

Install on Windows

Run the setup EXE, then open TumbStone Alpha from the Start menu. The installers include WebView2. Both editions can coexist.

These installers are unsigned. SmartScreen may show a warning; after checking the source, More info → Run anyway may be available.

Smart App Control or organization policy can block installation entirely.

Before you play

  • All editions include the same network and support sizes 6 and 8. Sizes 10 and 11 are experimental.
  • No Python or development tools are needed. NVIDIA editions need the graphics driver, with no CUDA Toolkit or cuDNN installation.
  • Copy your game text before closing. Automatic game restoration is not included in this alpha.
  • Tested on an M2 MacBook Air, an RTX 3080 Ti on Linux, and an RTX 5070 on Windows. Other systems need tester feedback.

Verify a download

Download its SHA256 file into the same folder. On Linux run sha256sum -c FILENAME.sha256; on macOS run shasum -a 256 -c FILENAME.sha256. On Windows compare Get-FileHash .\FILENAME.exe -Algorithm SHA256 with the checksum file.
